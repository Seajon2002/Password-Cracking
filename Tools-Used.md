# 🛠️ Tools & Technologies – Week 3

This document describes the tools and technologies used during my Week 3 cybersecurity internship practical tasks.

## 1. Kali Linux
A Linux-based operating system used for cybersecurity testing and penetration testing activities.

## 2. John the Ripper (JTR)
A password security auditing tool used to perform dictionary-based password cracking.

## 3. RockYou Wordlist
A commonly used wordlist for password auditing and dictionary attack exercises.

Used to extract crackable password hashes from encrypted PDF files in the practical lab.

## 5. NetworkWalks Dictionary Attack Lab
Used to understand and practice dictionary-based password attacks.

## 6. PDF Hash Extraction Tool
Used to extract password hashes from authorized encrypted PDF files.
